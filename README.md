# EdgeEver Web Companion (网页伴侣) 🌐

> 像在浏览器中一样浏览！直接在笔记中嵌入全功能全尺寸 Mini 浏览器，支持在地址栏修改网址一键回车跳转、自适应铺满编辑器全宽、高度顺畅拖拽拉伸与防白屏容灾机制。

---

## ✨ 核心特性

- 🖥️ **像在浏览器中一样浏览 (Embedded Mini Browser)**：
  - 顶栏配备类似 Chrome / Safari 的全功能智能地址栏 (Omnibox)；
  - **直接在地址栏内修改网址或粘贴新链接，敲击回车 (Enter) 即刻前往新网页，并自动保存到笔记**！
  - 配备 macOS 交通灯三色控件装饰、一键重新加载 (`🔄`)、安全连接锁 (`🔒`)。
- 📐 **自适应编辑器全宽 (Editor Breakout)**：
  - 突破笔记默认居中窄行（750px）限制，卡片自动侦测主编辑工作区宽度，**舒展铺满整个主工作区**（左右保留 24px 优雅呼吸留白），大幅拓宽浏览视野；
  - 顶栏一键切换「📐 全宽 / 📏 宽屏(980px) / 📝 标准」三种模式。
- ↕️ **高度自由顺滑拖拽与持久化**：
  - 底部配备 Mac 触控板质感的伸缩把手，拖拽时自动隔离底层网页事件拦截，丝滑跟手绝不卡死；
  - 拖拽松手即刻持久化保存高度数值至笔记属性中；
  - 支持 **双击底部把手** 在默认舒适高度 (720px) 与撑满当前屏幕高之间一键切换。
- 🛡️ **防白屏容灾双层架构 (Zero-Blank Guard)**：
  - 优先调用 EdgeEver 官方后台 `network.fetch` 穿透拉取无 CORS 限制源码并动态清洗 CSP 标签（如 `yinghezhinan.com` 等网站完美内嵌呈现）；
  - 针对设置了极端严格防嵌策略 (CSP: `frame-ancestors 'none'`) 的外部站点（如 GitHub），底层预置高颜值深色浏览器引导卡片与一键直达系统独立浏览器通道，**绝无刺眼大白屏**！
- ⚡ **输入 `/web` 随处插入**：
  - 在正文任意位置输入 `/web` 按回车或空格，即刻呼出输入弹窗（自动读取剪贴板链接），回车快速插入。

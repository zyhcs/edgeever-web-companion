# EdgeEver Web Companion (网页伴侣) 🌐

> 极致纯净、无侵入的内嵌网页浏览套件。在笔记中输入 `/web` 即可一键插入全尺寸交互式 iframe 网页，与笔记排版完美融合。

---

## ✨ 核心特性

- ⚡ **输入 `/web` 随处插入**：在笔记正文任意位置输入 `/web` 按回车或空格，即刻呼出极简输入弹窗（自动读取剪贴板链接），回车快速插入。
- 📐 **自适应编辑器主区域全宽 (Editor Breakout)**：突破正文居中窄行（750px）限制，卡片自动侦测主编辑工作区宽度并舒展铺满（左右保留 20px 舒适留白），大幅拓宽网页浏览视野！支持顶栏一键切换「全宽 / 宽屏 / 标准」三种模式。
- ↕️ **高度自由顺滑伸缩与持久化**：底部配备 Mac 精致拖拽把手，彻底消灭 iframe 鼠标截获导致的拖拽卡死断开问题；拖拽完毕自动将高度回写保存到笔记；支持双击快速撑满屏幕。
- 🎨 **Mac 极简精致暗黑磨砂设计**：缩窄顶栏（34px 极致微视窗），采用毛玻璃磨砂（`backdrop-filter: blur(16px)`）与经典 macOS 三色小圆点装饰，视觉质感与笔记完全融合。
- 🚫 **零外挂纯净无扰**：彻底移除正文顶部任何常驻悬浮按钮，完全不破坏笔记排版与阅读沉浸感。随时输入 `/web` 或按下 `Alt + W` 即可随心插入。
- ⚙️ **网页链接与标题随时编辑**：悬停标题即见微提示，点击标题或点击「⚙️ 设置」按钮，随时修改已插入网页的 **URL 目标链接**、**标题名称 (Title)** 以及 **宽度与高度**，修改后即时刷新并**持久化回写保存至笔记**！

---

## 🚀 使用方法

1. 在任意笔记中，换行输入 `/web` 并按下 `Enter` 或 `空格`（亦可随时按 `Alt + W`）；
2. 在弹出的对话框中输入或粘贴网页地址，按回车确认；
3. 当前位置即可生成自适应铺满编辑器全宽的内嵌网页视窗；
4. 鼠标按住卡片底部的 **拖拽手柄** 即可自由调节高度（松开即自动保存），双击手柄可快速撑满屏幕高度；
5. 点击顶栏标题或 **「⚙️ 设置」** 可随时修改网址、自定义标题、切换宽度模式与微调高度。

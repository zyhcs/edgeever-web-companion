# EdgeEver Web Companion (网页伴侣) 🌐

> 极致纯净、无侵入的内嵌网页浏览套件。在笔记中输入 `/web` 即可一键插入全尺寸交互式 iframe 网页，与笔记排版完美融合。

---

## ✨ 核心特性

- ⚡ **输入 `/web` 随处插入**：在笔记正文任意位置输入 `/web` 按回车或空格，即刻呼出极简输入弹窗（自动读取剪贴板链接），回车快速插入。
- 🎨 **Mac 极简精致暗黑磨砂设计**：缩窄顶栏（34px 极致微视窗），采用毛玻璃磨砂（`backdrop-filter: blur(16px)`）与经典 macOS 三色小圆点装饰，视觉质感与笔记完全融合。
- 🚫 **零外挂纯净无扰**：彻底移除正文顶部任何常驻悬浮按钮，完全不破坏笔记排版与阅读沉浸感。随时输入 `/web` 或按下 `Alt + W` 即可随心插入。
- ⚙️ **网页链接与标题随时编辑**：悬停标题即见微提示，点击标题或点击「⚙️ 设置」按钮，随时修改已插入网页的 **URL 目标链接**、**标题名称 (Title)** 以及 **视窗高度**，修改后即时刷新并**持久化回写保存至笔记**！
- 🖥️ **整页全尺寸 iframe 视窗**：插入的网页默认以全尺寸高度嵌入，打开笔记即可畅快浏览与交互。
- 🚀 **防嵌保护无缝直达**：针对启用了安全防嵌保护的站点，底层无缝预置自适应磨砂卡片与「🚀 在浏览器打开」大按钮，秒级直达。
- ⛶ **一键铺满笔记 (Fullscreen)**：支持一键将当前内嵌网页全屏铺满整个笔记视口，打造沉浸式全屏浏览体验。
- ↕️ **高度自由伸缩**：底部配备拖拽条，随时按住向下/向上调整网页在笔记中的显示高度。

---

## 🚀 使用方法

1. 在任意笔记中，换行输入 `/web` 并按下 `Enter` 或 `空格`（亦可随时按 `Alt + W`）；
2. 在弹出的对话框中输入或粘贴网页地址（如 `https://skillry.dev` 或文档链接），按回车确认；
3. 当前位置即可生成全尺寸内嵌网页，直接在笔记中浏览使用；
4. 需要修改网址或自定义标题时，直接点击卡片顶栏标题或右侧 **「⚙️ 设置」** 即可呼出修改面板。

---

## ⌨️ 快捷键

- `Alt + W`：快速唤起插入网页对话框
- 可以在命令面板中搜索 `Web Companion: /web 插入网页` 快速触发。

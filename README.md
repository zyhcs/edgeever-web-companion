# EdgeEver Web Companion (网页伴侣) 🌐

> 极致纯净、无侵入的内嵌网页浏览套件。在笔记中输入 `/web` 即可一键插入全尺寸交互式 iframe 网页，与笔记排版完美融合。

---

## ✨ 核心特性

- ⚡ **输入 `/web` 随处插入**：在笔记正文任意位置输入 `/web` 按回车或空格，即刻呼出极简输入弹窗（自动读取剪贴板链接），回车快速插入。
- 🖥️ **整页全尺寸 iframe 视窗**：插入的网页默认以全尺寸（高度自动撑满当前屏幕笔记高度）嵌入，打开笔记即可畅快浏览与交互。
- 🚀 **防嵌保护无缝直达**：针对启用了安全防嵌保护 (CSP: `frame-ancestors 'none'`) 的外部站点，视窗顶部配备高亮 **「🚀 在浏览器打开」** 按钮，一键在系统独立窗口中查阅。
- ⛶ **一键铺满笔记 (Fullscreen)**：支持一键将当前内嵌网页全屏铺满整个笔记视口，打造沉浸式全屏浏览体验。
- ↕️ **高度自由伸缩**：底部配备拖拽条，随时按住向下/向上调整网页在笔记中的显示高度。
- 🔄 **快捷实用工具**：顶部集成专属工具栏：一键刷新、复制网址链接、域名与来源展示。

---

## 🚀 使用方法

1. 在任意笔记中，换行输入 `/web` 并按下 `Enter` 或 `空格`；
2. 在弹出的对话框中输入或粘贴网页地址（如 `https://yinghezhinan.com/`），按回车确认；
3. 当前位置即可生成全尺寸内嵌网页，直接在笔记中浏览使用！

---

## ⌨️ 快捷键

- `Alt + W`：快速唤起插入网页对话框
- 可以在命令面板中搜索 `Web Companion: /web 插入网页` 快速触发。
